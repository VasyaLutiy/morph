### 2.2. OUTPUT data shapes

**`src/git/log.ts`** (NEW, layer git; imports `./run.js` only) — exports, in this order:

```ts
export interface MorphCommit { sha: string; card: string; model: string; run: string | null; paths: string[] }
export const MORPH_LOG_FORMAT =
  "%x1e%H%x1f%(trailers:key=Morph-Card,valueonly,separator=%x1d)%x1f%(trailers:key=Morph-Model,valueonly,separator=%x1d)%x1f%(trailers:key=Morph-Run,valueonly,separator=%x1d)%x1f";
export function readMorphLog(root: string, env: Record<string, string>): MorphCommit[];
```

**Read Morph Log** — the record's behaviour, exactly:

1. `runGit(root, ["rev-parse", "--verify", "-q", "HEAD"], env).code === 1` → `[]` (a repository with no commit). Any other
   code goes on (not a repository: the log below throws).
2. `out = gitOk(root, ["log", "-z", "--name-only", "--no-renames", "--format=" + MORPH_LOG_FORMAT], env)`.
3. `out.split("\x1e").slice(1)`; per record: `cut = record.lastIndexOf("\x1f")`; `record.slice(0, cut).split("\x1f")` →
   sha, card, model, run, each value `(v ?? "").split("\x1d")[0].trim()` (the first of repeated trailers); paths =
   `record.slice(cut + 1).split("\0")`, each with ONE leading `"\n"` removed, `""` dropped, git's order kept.
4. Walk the records in order, `current = null`: card ≠ `""` → push `{sha, card, model, run: current, paths}` (keys in this
   order; current unchanged); else run ≠ `""` → `current = run`; else `current = null`.

`{card, model, run}` (only these keys; a `sha` or other key of the input is not copied) to its writes. The input is not
changed. Keys in the interfaces' order.

## 4. Constraints

- NodeNext: every relative import carries `.js`; types with `import type`. No `any`.
- Layer git: `src/git/log.ts` spawns only through `./run.js` (runGit, gitOk; guard: `node:child_process` only in
  `src/git/run.ts`); no `process`, no clock. `src/git/ownership.ts` imports nothing.
- Layer primer (guard, P12a): renderPrimer.ts imports nothing; primerCommand.ts the only file that reads files, calls git
  and formats the clock.
- A file a card writes is in no sibling's slice in the same generation: generation 0 (read-morph-log, read-ownership,
  render-primer) — none reads another; generation 1 (primer-command + the three judges) — no judge reads primerCommand.ts,
  primer-command reads no test file; generation 2 (primer-command-judge).
- Tests write only under `tmpRoot()`/`tmpRepo()` and remove it in `finally`; no timer; a judge writes only its targets.
